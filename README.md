# YRL Wijesekara - Software Engineer Portfolio

This is a personal portfolio website for YRL Wijesekara, a Software Engineering undergraduate and Full-Stack Developer. The site showcases projects, skills, experience, and contact information.

## Features
- Responsive design for desktop and mobile
- Animated hero section and smooth scroll
- Featured projects with images and GitHub links
- Skills and technologies with progress bars
- Contact form and social links
- Custom cursor and scroll progress bar

## Technologies Used
- HTML5
- CSS3 (with Bootstrap Icons)
- JavaScript (vanilla)

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. All assets are local; no build step required.

## Customization
- Update your profile image in `assets/images/profile/`.
- Add or edit projects in the `index.html` and corresponding images in `assets/`.
- Update contact information in the contact section of `index.html`.
